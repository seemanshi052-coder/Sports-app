# TEAM RULES

## 1. One system

We have:

- One PostgreSQL database
- One Supabase Auth
- One FastAPI backend
- One Supabase Storage
- Flutter mobile
- Lovable web dashboard

## 2. No direct main development

Use feature branches.

## 3. Pull before starting

git checkout main
git pull

## 4. Small commits

One meaningful feature/change per commit.

## 5. No secrets

Never commit .env.

## 6. API contract

Do not casually change API response formats.

## 7. End-to-end

A feature isn't finished until the relevant complete flow works.

## 8. Ask before architectural changes

Do not introduce another database/backend/auth system.

## 9. Test

Every important feature needs tests.

## 10. Communicate

If your change affects another layer, tell the team.
